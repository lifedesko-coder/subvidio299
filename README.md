# BollywoodSub AI 🎬

محرك ترجمة سينمائي متقدم مبني على Google Gemini مع معادلة مزامنة حتمية (Base-60) لمنع تراكم أخطاء التوقيت ودعم كامل لملفات الفيديو والأفلام والمسلسلات الهندية الكبيرة.

## المزايا:
- دعم كامل لحلقات المسلسلات الطويلة (20 إلى 45 دقيقة).
- مزامنة Base-60 حتمية لضمان تطابق توقيت بداية ونهاية الحوارات بدقة.
- استخراج وترقية الصوت البشري مع فلاتر تقليل الضوضاء الديناميكية عبر FFmpeg.
- دعم اللهجات المتعددة: الفصحى الحديثة (MSA)، العراقية، المصرية، الشامية، والخليجية.
- استبعاد المؤثرات الصوتية والبيئية غير الحوارية والتركيز الحصري على كلام الممثلين والأغاني.
- تصدير الترجمة بصيغ متعددة: SRT القياسي، WebVTT، وملفات ASS ذات الستايل السينمائي الذهبي.
