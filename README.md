## المزايا والقدرات:
- **دعم كامل للحلقات الطويلة:** يترجم ملفات بطول 20 إلى 45 دقيقة وأكثر دفعة واحدة دون تقطيع أو توقف.
- **مزامنة زمنية حتمية (Base-60):** معادلة رياضية تضمن مطابقة الدقيقة لـ 60 ثانية ومنع خطأ الـ 100 ثانية الشائع.
- **تصفية المؤثرات وسارجام:** استبعاد تلقائي لتمارين السلم الموسيقي الصوتي (Sa Re Ga Ma) والآهات والمؤثرات البيئية (طرق الباب، خطوات، ضحك/بكاء بدون حوار).
- **التقاط الحوارات الخافتة:** توقيت متطابق مع أول همسة أو كلام في المشاهد الهادئة والدرامية.
- **تصدير متعدد الصيغ:** SRT القياسي، WebVTT، وملفات ASS ذات الستايل السينمائي الذهبي عالي الوضوح.
